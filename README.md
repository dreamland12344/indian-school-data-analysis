# Indian School Data Analysis Dashboard

## Project Overview

This project analyzes Indian school data using Microsoft Excel to identify trends and present insights through an interactive dashboard.

## Tools Used

* Microsoft Excel
* Data Cleaning
* Pivot Tables
* Pivot Charts
* KPIs and Slicers

## Project Deliverables

* Cleaned dataset
* Interactive Excel dashboard
* Data cleaning report

## Objective

To organize school data, analyze key metrics, and present findings in a clear, visual format.
